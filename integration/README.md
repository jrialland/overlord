# "Integration" tests

This folder contain tests that are not "unit" test and need to conform to particular settings to work.

## Required

- Ollama has to be installed and running.
- The 'lfm2.5-thinking:1.2b' model has to be present ( `ollama pull lfm2.5-thinking:1.2b` )
- The 'glm-5:cloud' model has to be present ( `glm-5:cloud` )
- The 'nomic-embed-text-v2-moe:latest' model has to be present ( `ollama pull nomic-embed-text-v2-moe:latest` )
